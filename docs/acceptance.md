10 万条内存快照查询微基准：2228 ns/op、328 B/op、5 allocs/op（一次本机运行，非 P95）。这是缓存查询的成本，不含 IPC、真实仓库扫描、磁盘遍历或 UI 渲染。COM 冒烟测试首个查询约 0.25ms、同路径缓存命中约 0.001ms；样本不足以声称达到 P95 指标。

性能边界：扫描进程并发为 1、watch 数量上限 2048、注册上限 256；监听失败/溢出后周期校验。每条 Git 命令 stdout 上限 8MiB、stderr 64KiB；IPC 单帧 8MiB，大结果会报错。当前未完成 1 万/10 万真实文件、超大 Diff、网络远程认证、Hook 子进程取消和低内存故障注入验收。

后续阶段功能：Rebase、Cherry-pick、Blame、LFS、Submodule 操作、三方 Merge、Stash、Tag、自动更新。当前 Submodule 状态字段可解析，不等于支持 Submodule 管理操作。根路径包含换行或非 UTF-8 字节尚不支持注册；仓库内普通文件名按字节保留。

发布门槛：在 Windows VM 和 macOS Apple Silicon 分别运行 CI、原生扩展集成、故障恢复、权限隔离、卸载与升级测试；完成可信签名、macOS 公证与真实设备 P50/P95 基线后再作为正式版本分发。
