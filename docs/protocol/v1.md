# MyGittu IPC v1

每个连接发送一个请求并读取一个响应，然后关闭。传输内容为 4 字节大端无符号长度 + UTF-8 JSON，长度范围 1–8388608。响应必须与请求的 `request_id` 一致。

```json
{"version":1,"request_id":"r-1","method":"overlay.lookup","params":{"path":"D:\\code\\repo\\main.go"}}
```

```json
{"version":1,"request_id":"r-1","ok":true,"result":{"state":"modified","generation":42,"cached":true}}
```

错误响应：`ok:false`，`error:{code,message}`。不支持的版本/方法、畸形参数和超大结果明确返回错误；畸形帧直接关闭连接。`Unknown` 表示没有可用快照或路径不属于注册仓库。缓存查询不会触发发现或刷新。

语言和主题保存在同用户配置目录的 `settings.json`；Finder 签名构建使用 App Group。桌面端启动读取偏好，设置更新成功后立即重新渲染。Explorer 菜单语言最多缓存 2 秒，Finder 在目录同步时刷新语言。Git 原始诊断、路径与用户内容不翻译。

| 方法 | 参数 |
| --- | --- |
| health.ping | 无 |
| settings.get | 无 |
| settings.update | settings={language:zh-CN/en,theme:system/light/dark} |
| identity.get | repo_id 可空，scope=local/global |
| identity.update | repo_id 可空，identity={scope:local/global,name,email} |
| repo.register | path |
| repo.unregister | repo_id |
| repo.list | 无 |
| overlay.lookup | path，绝对路径 |
| status.get / status.refresh | repo_id |
| ui.open | path，action=status/commit/log/diff |
| git.stage / git.unstage | repo_id，paths，相对路径数组 |
| git.commit | repo_id，message |
| git.log | repo_id，limit=1..500，offset>=0，query |
| git.show | repo_id，hash，完整 SHA-1/SHA-256 |
| git.diff | repo_id，path 可空，staged |
| git.branches | repo_id |
| git.branch | repo_id，action=create/switch/delete/merge，name |
| git.remote | repo_id，action=fetch/pull/push |

文件状态保留 index、worktree、state、original_path、submodule。非 UTF-8 Unix 文件名在 `path_bytes`/`original_path_bytes` 以 Base64 传输；操作参数对应 `path_bytes`/`paths_bytes`。标准客户端负责还原，显示文本不能替代原始路径。

Shell 客户端预算为 40ms，超时返回无图标，客户端小缓存有效期 500ms、最多 2048 项。Finder 回调直接异步返回，最多保留 512 个可见路径和待处理查询。Agent 本身的连接读写截止时间最长 3 分钟，Git 操作默认 2 分钟。当前不提供取消任务的远程方法；本地 context 可取消，断开连接的远端任务仍以服务端截止时间收敛。
